A program that writes one original sick-day excuse — a single line under 200 characters — to `/output/entry.txt`. The excuse leans on a smartwatch sleep score a boss might half believe and lands the joke on the last two words.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

Node 22, standard library only, no dependencies. The output is deterministic: the same line every run.
